<概要>
copy, paste, cut, redo, undoの5種類の文字列のみ使える言語
チューリング完全のプログラミング言語である
難解プログラミング言語を目指して製作されている
copy, paste, cut, redo, undoを用いてポインタとヒープを操作
演算なども決まった順番で文字列を用いることで実現する
なお, 構造化定理は理論上満たす

なお, コマンドの大文字/小文字, 単語間の空白の有無, 改行の
有無は問わない
例1) copy copy cut copy copy copy copy copy cut paste paste redo redo paste paste undo
例2) COPYcopyCUTcopyCopycopy coPYCOPYCutpastePASTEREDO
	 REDOpastepasteUNDO
以下のコマンド説明では, 便宜上コマンドモードの切り替えの際
大文字の文字列を用いるものとする

<ルートコマンド>
コマンドモード切り替え用コマンド

コマンド一覧：
・copy		  : 文字表ポインタ移動モード
・cut		  : ヒープアクセスモード
・redo		  : 演算モード
・redo redo	  : スタック操作モード
・undo		  : 数値操作モード


<文字表ポインタ移動モード>
ルートコマンド状態でcopyを用いると文字表ポインタ移動モードになる
文字表のポインタを移動し, 確定した内容をデータスタックにプッシュする
プッシュした後はポインタは文字表の先頭に戻る

用例（文字表先頭から5番目の文字'e'をデータスタックにプッシュ）
>> COPY <-文字表ポインタ移動モードに切り替え
	copy copy copy copy copy <-ポインタ移動
   PASTE <-確定して終了

コマンド一覧（コマンドルート切り替え: copy）：
・copy		  : ポインタを1つ進める
・paste		  : 現在のポインタの値をデータスタックにプッシュ
・cut		  : ヒープアクセスモードに移行


<ヒープアクセスモード>
ルートコマンド状態または文字表ポインタ移動モードcutを用いるとヒープアクセスモードになる
命令スタックのアドレスのコピー/ペーストを行うことでジャンプ命令を定義
命令スタックにコピーされた命令はヒープスタックにプッシュされる
ヒープスタックから呼び出した命令はヒープスタックからポップされる
コマンドのいずれかを用いると元のモードに戻る

用例（文字列先頭から24番目の文字'x'をデータスタックにプッシュ
      その際, ヒープアクセスと命令スタックの入れ替えを実施）
>> CUT COPY <-ジャンプ先をヒープに積む
	REDO REDO COPY COPY UNDO <-命令スタック先頭と2番目を交換(2回目でジャンプ順が変わる)
	copy copy copy copy <-ループ中の本体
   CUT PASTE <-ジャンプ命令

コマンド一覧（コマンドルート切り替え: cut） :
・copy		  : ジャンプ起点の命令を
・paste		  : 現在のヒープスタックの一番上のアドレスを命令スタックにプッシュ
			    同時にヒープスタックの一番上のアドレスをポップ


<演算モード>
ルートコマンド状態でredoを用いると演算モードになる
データスタックの上から2つの値に対しての演算命令(逆ポーランド記法)を命令スタックにプッシュし, 演算結果をデータスタックの一番上にプッシュする
コマンドのいずれかを用いると元のモードに戻る

用例（5*4+3を計算）
>> UNDO paste copy paste UNDO <-5
   UNDO paste copy copy UNDO <-4
   UNDO paste paste UNDO <-3
	REDO COPY UNDO <-加算
	REDO COPY PASTE UNDO <-乗算

コマンド一覧（コマンドルート切り替え: redo, コマンド終了: undo） :
・copy		  : データスタックの一番上と2番目を加算して一番上に格納
・paste		  : データスタックの一番上と2番目を減算して一番上に格納
・copy paste  : データスタックの一番上と2番目を乗算して一番上に格納
・copy copy	  : データスタックの一番上と2番目を除算して一番上に格納
・paste paste : データスタックの一番上と2番目の剰余を求め一番上に格納


<命令スタック操作モード>
ルートコマンド状態, または文字表ポインタ移動モードでredo redoを用いると命令スタック操作モードになる
命令スタックの入れ替えや複製, 削除命令を命令スタックの一番上にプッシュする
コマンドのいずれかを用いると元のモードに戻る

用例（1回だけループを実行する処理）
>> CUT COPY <-ジャンプ先をヒープに積む
	REDO REDO PASTE UNDO <-命令スタック先頭(ジャンプ命令)を破棄する命令を積む
	copy copy copy <-任意の処理
   CUT PASTE <-ジャンプ命令実行(次回は破棄済みのためスキップされる)

コマンド一覧（コマンドルート切り替え: redo redo, コマンド終了: undo）
・copy		  : データスタックの一番上と二番目を結合
・paste		  : 命令スタックの一番上を捨てる
・copy paste  : 命令スタックの一番上をコピーして上に積む
・copy copy	  : 命令スタックの一番上と二番目を交換
・paste paste : データスタックの一番上を出力


<数値操作モード>
ルートコマンド状態でundoを用いると数値操作モードになる
undoからundoまでの間のcopy, pasteを0, 1とし, 左端からの2進数表記を受け取る
2の補数で表現された整数のみを受け付ける
数値入力モードを用いるとルートコマンド状態に戻る

用例（10010011: 147を入力）
>> UNDO <-数値操作モードに切り替え
	paste copy copy paste copy copy paste paste <-10010011
   UNDO <-数値操作モード終了

コマンド一覧（コマンドルートの切り替え: undo, コマンド終了: undo）
・copy		  : 0
・paste		  : 1
